# Squire practice room

Public pages for Squire.Coach (home, privacy, terms) and its web pages for invited feedback (`board/`). Served by GitHub Pages; room.squire.coach once its DNS exists.

This repo is public and holds only the page itself: HTML, CSS and JavaScript. It contains **no secrets**. The only key in it will be Supabase's publishable key, which is designed to be public; every row and file is protected by row-level security on the server. Rooms never touch GitHub: nothing here reads any repo.
